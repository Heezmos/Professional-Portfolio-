# Portfolio project screenshot assets

Place the original, authentic product screenshots in this directory using these filenames:

| Project | Screenshot files |
|---|---|
| Ecofarms | `ecofarms-01.webp`, `ecofarms-02.webp`, `ecofarms-03.webp` |
| Delight Holdings | `delight-holdings-01.webp`, `delight-holdings-02.webp`, `delight-holdings-03.webp` |
| E-School Management | `e-school-01.webp`, `e-school-02.webp`, `e-school-03.webp` |
| EZGo | `ezgo-01.webp`, `ezgo-02.webp`, `ezgo-03.webp` |

Use screenshots captured from the real project interfaces, ideally at 1600 × 1000 or larger. Export as WebP, keep each image reasonably compressed, and avoid including real personal data, credentials, payment details, or confidential records.

The case-study galleries automatically display the matching files when they are added. Until then, the page shows a clearly labelled pending-evidence panel rather than inventing product screenshots.
