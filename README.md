# Heez Mos — Personal Portfolio

An editorial, motion-led portfolio exploring the intersection of business, technology and data.

## Development

This repository contains the active redesign work on the `chore/import-lovable-portfolio` branch.

```bash
npm install
npm run dev
npm run build
```

## Design direction

See [REDESIGN_DIRECTION.md](./REDESIGN_DIRECTION.md) for the concept, information architecture, animation principles, content integrity rules and implementation sequence.

## Current implementation

- Editorial hero with responsive 3D artwork (React Three Fiber / Drei).
- Scroll-reveal sections using Intersection Observer.
- Animated capability ticker and section transitions.
- Capabilities, selected work, experience/education and contact sections.
- Responsive layouts and reduced-motion CSS support.
- Portfolio content is being limited to verified experience and clearly labelled project stages.

## Important

This branch is a development workspace, not a production release. Do not merge into `main` or publish without review and explicit approval. Contact details and any additional career/project claims must be confirmed before public release.
